# Junha Seo

경북대학교 통계학과 석사과정 Junha Seo의 영문 학술 홈페이지입니다. HTML과 CSS가 한 파일에 들어 있어 별도 설치나 빌드 없이 사용할 수 있습니다.

## 파일 배치

```text
index.html
README.md
asset/
  profile.png
```

`asset` 폴더에 프로필 사진을 `profile.png`로 저장하세요. 사진은 중앙을 기준으로 원형으로 표시되며, 파일이 없으면 이니셜 JS가 표시됩니다. 로컬에서는 `index.html`을 브라우저로 열어 확인할 수 있습니다.

## GitHub Pages 배포

1. GitHub 저장소의 기본 브랜치 최상위에 위 구조대로 파일을 올립니다.
2. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
3. 파일을 올린 브랜치와 **/ (root)**를 선택하고 저장합니다.
4. 배포가 완료되면 같은 화면에 표시되는 사이트 주소를 엽니다.

## 수정

이름, 이메일, 학력, 논문 상태 등은 `index.html`의 해당 본문을 수정합니다. 이메일 변경 시 화면의 주소와 두 곳의 `mailto:` 링크를 함께 바꾸세요. 사진은 같은 경로에 새 파일로 교체하면 됩니다.
